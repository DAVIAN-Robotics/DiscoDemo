# DiscoDemo project page

Project page for **DiscoDemo: Discovering Efficient and Diverse Robot Demonstrations for Imitation Learning**.

Live at https://davian-robotics.github.io/DiscoDemo/

It is a static site with no build step. To preview it locally, serve the folder:

```bash
python -m http.server 8000
```

## Layout

- `index.html` — all page text.
- `static/css/style.css` — styles, including the light and dark themes.
- `static/js/` — video players, results chart and figure animations.
- `static/data/`, `static/figs/`, `static/traj/`, `static/opening/` — generated data for the players and figures.
- `static/images/`, `static/videos/` — images and rollout videos.
